# 制作手册

## 稿、声音、画面怎么接

- 写一句观众看完能回答的问题。查资料时使用 [来源表](../assets/source-register.tsv)：事实写论据；画面素材另写作者、链接、许可和要不要署名。资料写的年代和画面拍摄的年代分别核对。画不出来的真实史貌可以用示意图表达，但要标清。
- 为稿子编号，定稿后再录或配。用真实句界排镜头；需要在同一句里切两次，用外部剪辑把同句的多段画面先剪成一个视频片段，再把它放进这句的镜头槽位。台词过长就先删字或拆句。
- `build.py` 把每条镜头的累计时长换成帧，画面与中英字幕用同一组帧边界。镜头画面已经有字时，让脚本保留原画；新画面由脚本叠加标题、画面类别和字幕。视频素材原声会被忽略，旁白和配乐从命令行另接。

## 工程字段

从 [上海样片工程](../article/demo/project.json) 复制结构。顶层填写 `title`、`subtitle`、`width`、`height`、`fps` 和按播放顺序排列的 `shots`。

每条镜头记录 `id`（唯一小写英文/数字/短横线，首字符为字母）、`chapter`、`title`、`seconds`、中文 `zh`、英文 `en`、`source` 和 `kind`。画幅宽高用偶数。最开始的停顿或片尾留白也计入时间轴；旁白不能超过整片时长。媒体路径必须位于 `project.json` 的目录或子目录内。

| 镜头素材 | 字段和用法 |
| --- | --- |
| 照片、地图、生成的图片 | `kind: image`，`image` 是本地相对路径，`visual_role` 填「历史资料」「现代参照」或「示意图」。 |
| 实拍、档案视频、渲染好的动镜头 | `kind: video`，`video` 是本地相对路径；`source_frame` 是换算到项目帧率后的起始帧序号（默认 0）；设置 `visual_role`。只有画面已经烧录且与本次交付一致的字幕时，才设 `captions_in_picture: true`。源片段必须足够长。 |
| 快速画一个河岸概念 | `kind` 用 `river`、`wharf`、`bridge` 或 `city`。这些内置画面是草图，不代表真实城市。 |

## 验收和返修

按 [README](../README.md) 导出后，先在观看页检查每段跳转，试听人名、地名和数字，核对画面、旁白与双语字幕有没有错位。技术报告的轨道、帧数和全解码检查不能代替试听或主观审片。保留纸稿、干声、时间表、分镜、素材来源和成片，修改时用新输出目录。只修配音时优先替换最小的完整句段，尽量留住原有停顿和画面切点。
